
# OTUDOC

## How to build and run the app

OTUDOC is a Flutter app for Android. You need the Flutter SDK (stable channel), Android Studio with the Flutter plugin, and an Android emulator or phone. Clone the repository with git clone https://github.com/cpaul001/otudoc.git, open the otudoc folder in Android Studio, and run flutter pub get in its terminal to download the packages. The project uses Firebase Authentication, sqflite, shared_preferences, path_provider and file_picker. Firebase is already configured (google-services.json and firebase_options.dart are included), so no extra setup is needed. Start an Android emulator, select it in the device dropdown (not Chrome or Windows, since local storage only works on Android), and press Run, or run flutter run. Sign in with the test account [email / password], or create a new account on the sign-up screen. On Windows, Developer Mode must be turned on (Settings → For developers) for Flutter to build projects that use plugins.
